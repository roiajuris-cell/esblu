## Esblu does not use cookies

Esblu does not currently use any cookies — neither necessary nor optional (analytics, marketing, or preference cookies). Login and session persistence are handled exclusively by the browser's **localStorage** technology, used by the Supabase Auth login library — not by cookies.

Since localStorage is not a cookie and serves solely to keep you logged in while using the application after you sign in (it functions as a necessary/technical technology without which the service would not work), we do not display a cookie banner or consent request — this would serve no real purpose in this case, since no optional tracking takes place.

## Overview of browser storage used

- **Name/key:** `sb-<project-ref>-auth-token`
- **Type:** localStorage (not a cookie)
- **Purpose:** Maintaining login (session token) between visits to the site
- **Provider:** Supabase Auth
- **Category:** Strictly necessary

This storage is cleared upon logout or when browser data is manually cleared. It does not contain tracking identifiers for any purpose other than login.

## Analytics, advertising, tracking

Esblu does not currently use any third-party analytics, advertising, or tracking tool (e.g., Google Analytics, Meta Pixel, or similar) and does not integrate any external tracking script.

## Future changes

If Esblu were to start using cookies or similar technologies beyond those described above in the future (e.g., optional analytics), this page will be updated, and a consent tool (cookie banner) offering an equally easy way to accept or reject will be displayed before such technologies are deployed, as required by applicable rules.
